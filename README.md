# balletfit · demo del sitio web

Base de demostración para el estudio balletfit (Guatemala).

- `index.html` — página única con intro animada del logo, método, clases, horario, planes, cómo funciona, vista previa de paneles, clase de prueba y preguntas.
- `assets/js/main.js` — al inicio está `CONFIG`: WhatsApp, clases, horario y planes. Edita ahí los datos reales.
- `assets/img/logo.svg` — logo vectorizado (capas: cuerpo, brazo, cabeza, ballet, fit). `tools/trace_logo.py` lo regenera desde el JPG.
- Agrega `?sinintro` a la URL para entrar sin la animación.

Pendiente para la versión final: datos reales (WhatsApp, precios, horario, dirección, foto y biografía de Andrea), cuentas reales y pago en línea.
